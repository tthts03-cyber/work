# 売れた価格チェッカー

商品名を入れると、各サイトの「売れた・落札された」検索結果をワンタップで開けるスマホ向けWebアプリ（無料・サーバー不要）。

| サイト | 開くページ |
|---|---|
| ヤフオク | 落札相場（終了が新しい順） |
| メルカリ | 売り切れのみ（新しい順） |
| Keepa | Amazonの価格推移 |
| Amazon / 楽天市場 / Yahoo!ショッピング | 検索結果（楽天・Yahoo!は安い順） |

- 検索履歴は端末内（localStorage）に最大10件保存
- ホーム画面に追加するとアプリのように使えます

ローカルで試す: `python3 -m http.server` を実行して http://localhost:8000 を開く
